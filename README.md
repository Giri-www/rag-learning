# RAG Learning  🚀

A hands-on repository for learning **Retrieval-Augmented Generation (RAG)** from beginner to advanced level.

This project demonstrates how to build intelligent AI applications using **Large Language Models (LLMs), vector databases, embeddings, and modern retrieval techniques**.

The goal of this repository is to provide practical implementations of RAG pipelines used in real-world AI systems.

---

## 📚 What is RAG?

**Retrieval-Augmented Generation (RAG)** is an AI architecture that combines:

* **Information Retrieval** (searching relevant documents)
* **Large Language Models (LLMs)** (generating responses)

Instead of relying only on the model’s training data, RAG retrieves **external knowledge** and feeds it into the LLM to produce more accurate and up-to-date responses.

## 🧠 Learning Path

This repository follows a **step-by-step progression**:

```
rag-learning-lab

├── 03-multi-document-rag
```

### Project Overview

| Project            | Description                                  |
| ------------------ | -------------------------------------------- |
| Basic RAG          | Simple retrieval + LLM generation pipeline   |
| PDF RAG            | Chat with PDF documents                      |
| Multi Document RAG | Retrieve information from multiple documents |
| Hybrid Search RAG  | Combine semantic + keyword search            |
| Agentic RAG        | Use agents for intelligent retrieval         |
| Production RAG     | Scalable and optimized RAG pipeline          |

## ⚙️ Setup

Clone the repository:

```
git clone https://github.com/giri-www/rag-learning.git
```

Install dependencies:

```
pip install -r requirements.txt
```

Run a project:

```
cd 01-basic-rag
python app.py
```
